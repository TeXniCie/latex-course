\begin{frame}[fragile]{LaTeX commands}
    LaTeX commando's beginnen met een backslash \textbackslash, gevolgd door de titel van het commando.
    \pause

    Let op dat je het commando goed spelt, anders krijg je een error

    \pause
    Commando's kunnen \textbf{argumenten} hebben. Deze moeten tussen de accolades 
    \begin{minted}[autogobble,numbers=none]{tex} 
    { en } 
    \end{minted}
    \pause
    Dit argument is je eigen input en kan zijn wat je wil
    \pause
    voorbeelden

    \begin{minted}[autogobble,numbers=none]{tex}
        \commando
    \end{minted}
    of
    \begin{minted}[autogobble,numbers=none]{tex}
        \commando{blablabla}
    \end{minted}
